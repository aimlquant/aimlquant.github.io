OPERATING PRINCIPLES

공개보다 먼저 지키는 원칙

  • 원본 보존 — OBS 원본은 이동·삭제·덮어쓰지 않습니다.
  • 내용 단위 편집 — 긴 회의를 발표·운영·세미나처럼 시청 목적이 다른 영상으로 나눕니다.
  • 개인정보 최소화 — 이메일·계정·내부 주소는 크롭·마스크하고 실제 출력 프레임으로 다시 확인합니다.
  • 비공개 우선 — 영상·제목·자막·썸네일을 비공개 상태에서 확인한 뒤 건별로 공개합니다.
  • 공개 ID 분리 — 실제 공개된 영상만 공개 Pages에 임베드합니다.
